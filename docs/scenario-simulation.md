# حاسبة سيناريوهات المياه الزراعية

يوفر `POST /api/scenarios/simulate` مقارنة حسابية لسيناريو أساسي وسيناريوهات افتراضية للمحاصيل ذات الأولوية في تل أبيض والرقة. يجب إدخال قيم كل سيناريو صراحةً بالملليمتر:

- `seasonal_rain_mm`: المطر الموسمي المفترض
- `irrigation_mm`: إجمالي الري المفترض
- `available_soil_water_mm`: ماء التربة المتاح المفترض
- `crop_water_demand_mm`: احتياج مائي مفترض من مصدر موثق

مثال محلي توضيحي فقط، وليس قيماً موصى بها:

```json
{
  "crop_id": "wheat",
  "region_id": "tal_abyad",
  "baseline": {
    "seasonal_rain_mm": 250,
    "irrigation_mm": 80,
    "available_soil_water_mm": 40,
    "crop_water_demand_mm": 300
  },
  "scenarios": [
    {
      "name": "مطر أقل في الافتراض",
      "inputs": {
        "seasonal_rain_mm": 200,
        "irrigation_mm": 80,
        "available_soil_water_mm": 40,
        "crop_water_demand_mm": 300
      }
    }
  ]
}
```

تعيد الخدمة ميزان المياه الحسابي والفارق عن خط الأساس. لا تعيد غلة، احتمال مخاطر، أو كمية ري موصى بها. الحساب لا يمثل محاكاة DSSAT/APSIM، ويفترض كل المياه المدخلة متاحة بالكامل، ولا يحسب الجريان أو الصرف أو توقيت الأمطار أو معاملات المحصول. القاعدة السورية ما زالت مسودة؛ لا تستخدم النتائج كقرار حقلي دون تحقق البيانات ومراجعة مختص محلي.

شغّل الاختبارات بـ`python -m pytest -q`.
